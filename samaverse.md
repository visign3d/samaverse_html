# Samaversum

Samaversum is a speculative painting project exploring the idea of pseudo-life, memory, and artificial selfhood inside an imagined universe. It centers on Boltzmann Brains, unstable minds, and the strange persistence of identity within a simulated reality.

## Project links

- General description: [../samaverse.md](../samaverse.md)
- Model and schema overview: [../model/model.md](../model/model.md)
- Web presentation: [index.html](./index.html)

## Core concept

The project treats each image as a trace of a possible consciousness: a fragment of perception, a false memory, or a synthetic world-form emerging from noise. The artworks act as visual hypotheses about reality as something fragile, floating, and recursively constructed.

## Structure

- The gallery page renders the collection as a responsive visual archive.

## Notes

This project combines visual art, metadata, and archival presentation into a single conceptual framework: the universe is not just observed, but generated.
